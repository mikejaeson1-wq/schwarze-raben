Raben Admin · Nur für Admins

Die Clanführung.
Immer dabei.

Mitglieder freigeben, Beiträge pflegen und eure Website gestalten. Auf deinem Handy, mit deinem Discord-Konto.

Auf dein Handy holen.

Öffne diese Seite im Browser deines Handys. Die App lässt sich kostenlos auf dem Startbildschirm ablegen.

App öffnen

Android · Chrome

  1. Wähle App installieren, wenn der Button erscheint. Alternativ: Browsermenü ⋮ → App installieren oder Zum Startbildschirm hinzufügen.
  2. Bestätige die Installation und öffne das Symbol Raben Admin.
  3. Melde dich in der App mit Discord an.

iPhone · Safari

  1. Öffne Teilen → Zu Home-Bildschirm hinzufügen.
  2. Aktiviere Als Web-App öffnen, falls angezeigt, und wähle Hinzufügen.
  3. Öffne Raben Admin auf dem Home-Bildschirm und melde dich mit Discord an.

Scannen & öffnen.

Mit der Handykamera scannen. Der Code öffnet diese Anleitung; die Installation bestätigst du auf deinem Handy.
